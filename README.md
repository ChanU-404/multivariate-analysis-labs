## 사용 방법

R 및 RStudio를 준비하고 필요한 패키지를 설치하세요.

```r
install.packages(c("GGally", "MASS", "RColorBrewer", "ade4", "boot", "car", "data.table", "devtools", "dplyr", "ggResidpanel", "ggfortify", "ggplot2", "ggpubr", "gplots", "here", "knitr", "lattice", "lindia", "lmtest", "plyr", "psych", "scales", "stringi", "stringr", "tidyverse"))
```

각 스크립트의 입력 파일 경로와 작업 디렉터리를 로컬 데이터 위치에 맞춰 수정한 뒤 실행하세요. R Markdown 문서는 `rmarkdown` 패키지와 해당 출력 형식의 도구가 필요합니다.
